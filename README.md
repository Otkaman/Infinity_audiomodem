# Infinity_audiomodem

Во-первых, нужно установить `sample_rate` в `send.py` и `receptor.py` в соответствии с Гц вашего динамика/микрофона, иначе компьютеры будут тяжело конектится.

Запустите `run_rev.py` он начнет слушать поток, ища специальный сигнал. Когда он прозвучит начнет анализировать звук, выключается через 2 секунды тишины.

Когда включили `run_rev.py` можете включать `run.py` он передаёт файл и его имя через звук. Пока есть ограничение на размер файла (больше 100 Кб он физически не переварит ибо там O(n ** 2), где n - все байты, попытаюсь это поправить). Также используется сжатие.

Чтобы ускорить передачу измените `duration` в обоих файлах, однако у меня чем медленее, тем лучше данные передавались.

Насчет растояния, максимум - ноутбуки в +-20 см друг от друга (передали 5 Кб после 6 запусков неудачных).

Также тут есть моя заготовка с textual (папка `app`). Запустить можно через `run.py` (там комментарий)
