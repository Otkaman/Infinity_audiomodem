# Infinity Audiomodem

**Передавай файлы с одного ноутбука на другой через динамик и микрофон.**

Никакого Wi-Fi, Bluetooth или интернета. Только звук.

---

## Как это работает

1. Один ноутбук **играет** файл через динамик — это писк/шум
2. Второй ноутбук **слушает** через микрофон и расшифровывает
3. На выходе — тот же самый файл

---

## Установка

```bash
pip install -r requirements.txt
```

---

## Как отправить файл

**На первом ноутбуке:**

```bash
python sender.py --file myfile.zip --play
```

Выбери пресет под свои условия:

```bash
python sender.py --file myfile.zip --play --preset fast     # тихая комната
python sender.py --file myfile.zip --play --preset turbo    # макс. скорость
python sender.py --file myfile.zip --play --preset robust   # шум/большое расстояние
```

---

## Как принять файл

**На втором ноутбуке:**

```bash
python receiver.py --out incoming
```

Программа ждёт, пока не услышит конец передачи, и сохраняет файл в папку `incoming`.

Пресет должен совпадать с отправителем:

```bash
python receiver.py --preset fast --out incoming
```

## Флаги

### `sender.py`

| Флаг | Что делает |
|------|-----------|
| `--file FILE` | Какой файл отправить |
| `--text TEXT` | Отправить текст (вместо файла) |
| `--play` | Проиграть звук через динамик |
| `--save FILE.wav` | Сохранить звук в WAV-файл (для отладки) |
| `--preset NAME` | Пресет: `turbo`, `fast`, `medium`, `normal`, `robust` |

### `receiver.py`

| Флаг | Что делает |
|------|-----------|
| `--out DIR` | Папка, куда сохранить принятый файл |
| `--wav FILE.wav` | Взять звук из WAV-файла (для отладки) |
| `--preset NAME` | Пресет (должен совпадать с отправителем) |
| `--chunk-seconds N` | Длина блока записи (по умолчанию 5 сек) |

## Пресеты

| Пресет | Бит/с | 20 КБ за ~ | Когда использовать |
|--------|-------|-----------|-------------------|
| `turbo` | 500 бит/с | 5 мин | Полная тишина, ноутбуки рядом |
| `fast` | 333 бит/с | 8 мин | Тихая комната |
| `medium` | 67 бит/с | 30 мин | Небольшие помехи |
| `normal` | 25 бит/с | 90 мин | Обычные условия (по умолчанию) |
| `robust` | 10 бит/с | 4 ч | Шумное помещение, далеко |

## Проверить без второго ноутбука

```bash
# 1. Создать тестовый файл
python -c "open('test.bin','wb').write(b'\\x00'*20480)"

# 2. Закодировать в WAV
python sender.py --file test.bin --save test.wav --fast

# 3. Декодировать обратно
python receiver.py --wav test.wav --fast --out .

# 4. Сравнить — должно быть без отличий
fc /b test.bin test.bin
```

## Советы

- Ноутбуки поставь рядом (20–50 см)
- Тишина в комнате помогает
- Громкость динамика 50–70%
- Если не работает — попробуй обычный режим (без `--fast`)

## 🖥 TUI (Textual) интерфейс

Красивый консольный интерфейс с меню, прогресс-барами и логом:

```bash
python app.py
```

- **Отправить файл** — укажи путь или введи текст, выбери пресет, нажми Отправить
- **Принять файл** — нажми Слушать, жди маркер завершения, файл сохранится автоматически
- Все пресеты доступны из выпадающего меню
- Прогресс-бар и лог показывают что происходит
